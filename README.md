Stack

Stack is a linear data structure that follows the LIFO principle.

LIFO means Last In, First Out.

Main operations:

- Push – Insert an element
- Pop – Remove an element
- Peek – View the top element
- Display – Display stack elements

Example: A stack of plates.

Queue

Queue is a linear data structure that follows the FIFO principle.

FIFO means First In, First Out.

Main operations:

- Enqueue – Insert an element
- Dequeue – Remove an element
- Front – View the first element
- Display – Display queue elements

Example: A queue of people waiting in a line.

Array Implementation

In array implementation, elements are stored in a fixed-size array.

Advantages:

- Simple to implement
- Easy to access elements
- Fast operations

Limitation:

- Size is fixed

Linked List Implementation

In linked list implementation, elements are stored using dynamically created nodes.

Advantages:

- Dynamic size
- Memory is allocated as required
- No fixed size limitation

Difference Between Stack and Queue

Stack uses LIFO (Last In, First Out).

Queue uses FIFO (First In, First Out).

Stack insertion and deletion are performed from the top.

Queue insertion is performed from the rear and deletion from the front.

Applications

Stack applications:

- Function calls
- Undo and Redo
- Browser Back button
- Expression evaluation

Queue applications:

- Printer scheduling
- CPU scheduling
- Customer service systems
- Task scheduling
